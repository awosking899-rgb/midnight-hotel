# Midnight Hotel | فندق منتصف الليل (v0.3)

لعبة استكشاف 3D بمنظور الشخص الأول، لاعبان عبر الإنترنت. بلا اعتماديات npm (خادم WebSocket مكتوب يدويًا).

## الملفات
| الملف | الدور |
|---|---|
| `server.js` | خادم HTTP ثابت + WebSocket + غرف + حفظ JSON + `/healthz` |
| `public/index.html` | الواجهة العربية RTL: القائمة، إنشاء الشخصية، الحقيبة، الإعدادات |
| `public/game.js` | المحرك: الحركة، التصادم ثلاثي الأبعاد، الارتفاعات، الأبواب، الشبكة، الصوت |
| `public/content.js` | الطابق الأرضي الموسّع، NPC وحوار متفرع، الألغاز، النهايات، الأحداث |
| `public/tower.js` | البرج: السلم الحقيقي، المصعد، الطابق الأول، السطح، ألغاز الكتب والصور والخريطة |
| `public/ui.js` | نوافذ داخل اللعبة (لوحة أرقام، اختيار، ترتيب) بدل `prompt` |
| `test-multiplayer.js` / `test-client.js` | اختبارات الشبكة والمحرك |
| `Dockerfile`, `render.yaml`, `railway.json`, `.replit` | إعدادات النشر |

## التشغيل محليًا
`npm start` ثم افتح http://localhost:3000. الاختبارات: `npm test`.

## النشر والرابط المستقل
يلزم خادم Node دائم (ليس Netlify/Vercel الثابتين). ارفع المجلد إلى مستودع GitHub ثم:
- **Render:** New → Blueprint واختر المستودع (يقرأ `render.yaml`) أو Web Service: Start `node server.js`، Health `/healthz`. الرابط: `https://اسم-الخدمة.onrender.com`.
- **Railway:** New Project → Deploy from GitHub. ثم Settings → Networking → Generate Domain. أضف Volume على `/data` وعيّن `DB_FILE=/data/rooms.json`.
- **Replit:** Import from GitHub ثم Deploy (Reserved VM أو Autoscale). الرابط يظهر بعد النشر.
بدون قرص دائم يُحفظ الحفظ فقط حتى إعادة نشر/نوم الخدمة (القرص المؤقت يُمسح). الخطة المجانية في Render تنام وتفقد الملفات.

## اللعب من جهازين
أحدهما: «إنشاء غرفة» فيظهر الكود أعلى اليمين. الآخر: يكتب الكود في «انضمام» (أو يفتح `الرابط/?room=الكود`). حد أقصى لاعبان. عند قطع الاتصال تعاد المحاولة تلقائيًا بنفس الغرفة.

## حفظ الغرف
تُحفظ في `DB_FILE` (افتراضي `data/rooms.json`) كل 3 ثوانٍ وعند SIGTERM. اختُبر محليًا: إعادة تشغيل الخادم تُبقي الأبواب والمصعد والأدلة المشتركة والقرارات والهدايا غير المستلمة.

## التحكم
WASD + فأرة، Shift جري، E تفاعل، I الحقيبة. الهاتف: عصا يسار، سحب يمين، زر «تفاعل».
